# Java Banking Application

A simple console-based banking system in Java that supports basic banking operations such as deposit, withdrawal, balance check, and account details.

## 💻 Features
- Account creation with name and account number
- Deposit and withdraw with amount validation
- Balance inquiry
- Displays account details
- Exit function using `System.exit(0)`

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Console I/O with Scanner

## 🚀 How to Run
1. Clone the repo
2. Compile: `javac BankingApp.java`
3. Run: `java BankingApp`
